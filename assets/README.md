# Artwork / 图片说明

`hero.png` is a concept introduction banner generated with the built-in imagegen tool from a user-provided blue-haired chibi maid character reference. It illustrates Chat/Work navigation and one-click import; it is not a real product screenshot or an official endorsement.

`hero.png` 为根据用户提供角色参考、使用内置 imagegen 生成的功能介绍图。它展示聊天与工作区切换、一键导入的概念，并非真实界面截图。生成提示见 [hero.prompt.md](hero.prompt.md)。语言按钮 `lang-zh.svg` 与 `lang-en.svg` 为本地 SVG，链接到两份 README。
