# One-click transfer

First open a conversation, click **Transfer to work**, review the rendered range, select an existing workspace and accept the scope/context notices. Enable remembering that workspace and quick transfer. Later **One-click transfer** clicks save a local snapshot and persist native quoted context automatically, without another Send action.

The input remains empty. Import makes no model call; enter your next work task normally. The original webpage and archive remain available. Navigation back to Chat does not upload work history.

**Review before transfer** keeps the preview path available. **Transfer settings** lets you change the destination or disable quick mode. Target lists are checked against the real registry; loading/reconnecting waits are bounded at ten seconds. A failed list does not prove the workspace disappeared. A confirmed missing destination requires another selection.

Captures remain partial. Earlier unloaded messages, other branches and attachment bodies are not included; model context capacity is not estimated. Failures show a safe stage/code and preserve the source. Retrying the same request reuses the native ID; inspect the project for a pending import if persistence was interrupted. See [native history](NATIVE-HISTORY.md) and [contracts](CONTRACTS.md).
